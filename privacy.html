할 일 위젯 개인정보처리방침

시행일: 2026-11-09

1. 사용하는 정보

  • Google Tasks: 사용자의 할 일 목록과 할 일(제목, 기한, 완료 여부)을 읽고, 사용자가 위젯에서 요청한 경우에만 할 일을 추가하거나 완료 상태를 바꿉니다.
  • 이메일 주소: 허용한 계정이 정해진 계정인지 확인하는 데만 씁니다.

2. 저장과 공유

  • 로그인 토큰과 위젯 설정(우선순위·순서·중요 표시)은 사용자 PC 안에만 저장합니다.
  • 어떤 정보도 개발자 서버나 제3자에게 보내지 않습니다. 이 앱에는 서버가 없습니다.
  • 광고, 분석, 판매 목적으로 쓰지 않습니다.

3. Google API 사용자 데이터 정책 준수

이 앱이 Google API에서 받은 정보를 쓰고 옮기는 방식은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회

Google 계정 > 보안 > 타사 앱 및 서비스에서 언제든 이 앱의 권한을 지울 수 있습니다. PC의 토큰 파일을 지워도 연결이 끊깁니다.
